# 去 AI 腔门禁

成稿后、投递前跑一遍。三层递进：规则层（机械可查）→ 审问层（LLM 判断）→ 红线层（铁律直接拦）。**只标嫌疑、给依据和改法，改不改作者拍板；发布链不因门禁失败而阻断。**

规则移植自 wechat-publish-service `src/writing/tone.rs` + `gate.rs`（2026-09 线上验证版），阈值沿用原值。

## 统计纪律（规则层通用，防误伤的核心）

- **只统计散文**：剔除代码围栏块、标题行、引用行、HTML 注释、分隔线——代码里的「首先」不算 AI 腔
- 散文不足 200 字满分放行（提纲/短文不做密度统计）
- 所有问题一律 minor（提示不阻断——规则层只报事实，不替作者做决定）

## 第一层：确定性四规则（本地可机械执行）

1. **套话密度**：命中下方词表的处数 > 5 处/千字即报，附 top3 高频（如「总之×3、此外×2」）
2. **开头套路**：首段以「在当今 / 随着 / 众所周知 / 在信息爆炸 / 在这个」开头即报，建议从具体场景/痛点直接进入
3. **句长节奏**：句数 ≥8 时算句长变异系数，< 0.35 = 长短句缺乏起伏（每句等长的匀速文最典型）
4. **段首机械**：连续 3 段以前两字相同的词开头（如连续三段「我们…」）

### AI 腔套话表（单一事实源，规则与写作时的禁词规范共用）

首先 / 其次 / 再者 / 最后 / 总之 / 综上所述 / 总而言之 / 此外 / 另外 / 与此同时 / 不仅如此 / 更重要的是 / 在此基础上 / 作为一个 / 让我们 / 值得注意的是 / 需要指出的是 / 不可否认 / 毋庸置疑 / 众所周知 / 事实上 / 显而易见 / 可以说 / 从某种意义上说 / 非常重要 / 至关重要 / 不言而喻 / 具有重要意义 / 发挥着重要作用 / 意义深远 / 影响深远 / 引发了广泛关注 / 引起了热烈讨论 / 总的来说 / 综合来看 / 由此可见 / 不难发现 / 通过以上分析 / 正如我们所看到的

**词表增补约定**：此表是 2026-09 线上验证版快照，AI 腔会换代。每篇门禁中发现的、表外的新型套话/句式，随手补进本表（改仓即生效，软链用户自动跟进）；删除过时词同样走这里。

## 第二层：审稿四问（LLM 判断，每问 0-1 分，< 0.5 不通过）

1. **活人思考**：有没有作者自己的观点、判断或立场？纯客观转述、通篇没有「我」的痕迹 = 低分
2. **信息增益**：读者读完能带走什么新东西（新结论/新视角/新方法）？常识罗列 = 低分
3. **对话感**：语气像不像在跟一个具体的人说话？有无面向读者的称呼、提问或回应？论文式自说自话 = 低分
4. **共鸣入口**：开头是从读者的世界进入（读者经历过的现象/痛点），还是从作者自己的事进入（「我们做了/我发现」）？读者没有理由关心一个陌生人的流水线 = 低分

注：节奏起伏不设问——第一层规则 3 已覆盖，不重复。审问只依据正文（去标题行，长文截 8000 字）。

## 第三层：写作红线（既有铁律收编，命中直接拦，不走打分）

- **预期值冒充实测**：部署完成 ≠ 优化生效，效果数字必须实测，「预计提升」字样出现在效果段 = 拦
- **数字无参照系**：给了数字没给对比锚点（「省了 30%」——跟什么比？）
- **排版死角**：加粗跨标点、中英文标点混用（wechat-md 粗体标点坑同源）

## 执行方式

- 输出按层汇报：规则层逐条（原句 | 规则 | 改法）→ 审问层逐问（分数 + 一句话依据）→ 红线层直接拦
- 规则层命中 ≤2 处且审问全过 → 报「可发」，不逐条打扰
- 作者圈选后批量改，改完只报改动数，不重印全文
